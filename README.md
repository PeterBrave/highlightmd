# MarkLens

MarkLens is a local-first Markdown review reader with smart highlights and presentation mode.

It turns long Markdown documents, READMEs, PRDs, RFCs, and technical specs into scannable, presentation-friendly reading views.

## Web MVP

The first version includes:

- Paste Markdown
- Drag in `.md` files
- Markdown rendering
- Rule-based smart highlights
- Light / Review / Pitch / Tech modes
- Presentation mode
- Reading controls
- Local-only document processing

## Run

```bash
pnpm install
pnpm dev
```

The web app runs from `apps/web`. The repository name can remain `highlightmd`.
